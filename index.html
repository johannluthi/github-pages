Ajouter un projet

Crée un dossier (ex. mon-projet/) contenant un index.html, puis ajoute une entrée dans projects.json :

{
  "titre": "Mon projet",
  "url": "mon-projet/",
  "description": "En une phrase.",
  "tags": ["HTML", "SVG"],
  "date": "2026-09-01",
  "statut": "en ligne"
}

statut accepte en ligne, brouillon ou archivé. Le tri se fait par date, la plus récente en premier. Puis git add -A && git commit -m "maj" && git push.
